# Software access policy

## Whitelist

- 7-Zip — approved archive utility.
- Visual Studio Code — approved development editor.
- Google Chrome — approved business browser.
- Microsoft Teams — approved collaboration client.

## Blacklist

- uTorrent — prohibited peer-to-peer file sharing.
- BitTorrent — prohibited peer-to-peer file sharing.
- Cheat Engine — prohibited system modification tool.
- AnyDesk Portable — prohibited remote access software when not approved.
- KMSpico — prohibited license bypass tool.
